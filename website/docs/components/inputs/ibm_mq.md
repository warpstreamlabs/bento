This input consumes messages from an IBM MQ queue and forwards only the message payload content downstream.

Each message is read under syncpoint and committed once Bento acknowledges it. If Bento rejects the message, or the input disconnects before it is acknowledged, the message is backed out and stays on the queue.

The next message is read only once the previous one is acknowledged, so messages from this input cannot be batched at the output level.

By default Bento does not build with components that require linking to external libraries. If you wish to build Bento locally with this component then install the IBM MQ C client in `/opt/mqm` and set the build tag `x_bento_extra`:

```shell
# With go
go install -tags "x_bento_extra" github.com/warpstreamlabs/bento/cmd/bento@latest

# Using make
make TAGS=x_bento_extra
```

The resulting binary also needs the IBM MQ client libraries in `/opt/mqm` wherever it runs.

There is a specific docker tag postfix `-cgo` for C builds containing this component.

### `tls`

Optional IBM MQ TLS settings. TLS is handled by the IBM MQ C client rather than Go, so these fields differ from the `tls` fields of other components.


Type: `object`  

### `tls.enabled`

Enables TLS for the client connection.


Type: `bool`  
Default: `false`  

### `tls.cipher_spec`

The IBM MQ CipherSpec configured on the target channel.


Type: `string`  
Default: `""`  

```yml
# Examples

```

### `tls.key_repository`

Path to the key repository without the `.kdb` extension. The repository is a CMS key database (`.kdb`) with its password stash file (`.sth`) next to it. The IBM MQ C client initializes TLS once per process, so all `ibm_mq` inputs and outputs in a Bento process must use the same key repository, with `certificate_label` selecting each connection's certificate.


Type: `string`  
Default: `""`  

```yml
# Examples

key_repository: /opt/mqm/ssl/key
```

### `tls.certificate_label`

Optional label of the client certificate in the key repository. If empty, IBM MQ uses `ibmwebspheremq` followed by the user ID of the client in lowercase.


Type: `string`  
Default: `""`
