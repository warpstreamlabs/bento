Tokenizes text using a Hugging Face 🤗 tokenizer.

```yml
# Config fields, showing default values
label: ""
nlp_tokenize:
  path: "" # No default (required)
  add_special_tokens: true
```

Encodes the text of each message using a [Hugging Face tokenizer](https://github.com/huggingface/tokenizers) loaded from a local `tokenizer.json` file, replacing the message with a JSON object containing the token `ids`, `tokens` and `attention_mask`.

The tokenizer runs within a sandboxed WebAssembly runtime that can only read files within the current working directory, so the `path` must be relative to it.


## Fields

### `path`

The path to a `tokenizer.json` file, relative to the current working directory.


Type: `string`  

### `add_special_tokens`

Whether to add the special tokens defined by the tokenizer, such as `[CLS]` and `[SEP]`.


Type: `bool`  
Default: `true`
